# 塔科夫之狼

一款以现代城市生活、创业经营和资本投资为核心的单人 3D 模拟游戏。玩家在塔科夫市工作、管理个人生活、创办科技公司、研发产品并参与股票投资；城市人口、政府选举和城区建设会随游戏时间持续演化。

项目处于持续开发阶段，支持本地浏览器开发，Windows Electron 桌面版处于改造与验收中；无游戏后端服务，不包含多人联机。

## 已实现的功能

### 城市探索与时间

- 第三人称人物移动、疾跑、视角旋转、镜头缩放与建筑碰撞。
- 与银行、实业大厦、住宅、证券中心、政府和便利店交互。
- 连续游戏时间、速度调整、暂停、休息和睡眠；行情、工资、费用与月结使用同一套游戏时间。
- 城区建设完成后动态扩展道路、建筑与可活动范围。

### 个人生活与财务

- 现金、银行存款、存取款、个人贷款、还款和生活欠款。
- 求职、工作班次、工时统计、工资计提与月度发薪。
- 饱食度、水分及其对工作效率和移动的影响。
- 便利店购买食品饮料、背包管理与消耗品使用。
- 个人资产、负债、资金流水和历史月报。

### 企业经营

- 创建科技公司，管理独立企业账户，追加出资和分红。
- 聘用科研人才、投入研发、发布产品、设置售价与营销预算。
- 产品属性、发布代次、销售、经营成本、应付款与企业报表。
- 暂停、恢复与清算经营；AI 企业使用同一套业务规则。

### 投资与资本

- 股票买卖、持仓成本、市值、浮动盈亏、已实现盈亏与交易记录。
- K 线、十字线、价格提示、缩放和平移，以及股票详情浮窗。
- 企业股权、外部融资报价、主动上市、增发、回购与分红。
- 股东提案、投票和 CEO 任免；股份所有权与经营管理权限分开处理。

### 人口、政府与城市发展

- 城市人口自然增长、收入阶层流动及经济与股市影响。
- 不同政治群体、候选人、竞选赞助、选举和任期政策。
- 群体满意度、持续不满监测与提前选举规则。
- 游戏 GDP、经营产出、市场指数与城市统计。
- 选举后的建设条件判断、城区项目交付和 AI 企业招商。

### 房地产与住房

- 初始住所为免费永久居住权，不计入可出售资产。
- 住宅购买、挂牌、出售，储备土地购买及 AI 限时收购报价。
- 新住宅六个月玩家优先购买窗口，宏观居民按需求和实际资金逐月购房。
- 有可追踪旧房的家庭支持改善置换；群组储蓄与住房随人口转层对账。

### 界面与存档

- 统一的个人生活、企业经营、投资市场、城市事务和系统菜单分类。
- 可拖动、放大与恢复的浮动窗口，保留部分城市场景。
- 人口环形图悬停突出、图例联动与分类详情。
- 界面刷新保留输入草稿和滚动位置。
- 本地保存、读取、JSON 导入导出与旧版本存档迁移。

## 本地运行

需要安装 Node.js 和 npm。当前 Vite 要求 Node.js **20.19+（20.x）或 22.12+**，建议使用符合要求的 LTS 版本。

```bash
npm ci
npm run dev
```

打开终端显示的本地地址，通常为 `http://localhost:5173`。

Windows 也可双击 `start.cmd`。启动脚本需要可用的 Node.js/npm，首次运行会安装依赖。

其他命令：

```bash
npm run typecheck  # TypeScript 类型检查
npm run build      # 类型检查并生成 dist/
npm run preview    # 本地预览构建产物
```

构建产物需要通过 HTTP 静态服务访问，不要直接双击 `dist/index.html`。

## Windows 桌面版

桌面版使用 Electron 内置 Chromium 与本机资源协议，不要求安装 Node.js、npm、浏览器或 Vite 服务。详细架构、安全边界与数据位置见 [桌面版说明](docs/desktop.md)。

```bash
npm ci
npm run desktop:dev     # 开发：固定 127.0.0.1:5173 + Electron
npm run build           # 类型检查 + Vite 生产构建
npm run desktop:start   # 用 app://game/ 启动未打包生产构建（需先 build）
npm run desktop:build   # 生成 NSIS 安装包到 release/
```

安装包默认创建桌面与开始菜单快捷方式，升级和卸载保留用户数据。桌面版存档位于 `%APPDATA%\WolfOfTarkov`，与浏览器存档相互独立；迁移请使用游戏内「导出 JSON / 导入 JSON」。卸载不会自动删除该目录。

```text
release/WolfOfTarkov-Setup-0.3.3.exe
```

桌面版当前只发布 Windows x64，安装包未签名；首版不包含自动更新。

## 基本操作

| 操作 | 按键或入口 |
| --- | --- |
| 移动 | W / A / S / D 或方向键 |
| 切换疾跑 | Shift |
| 转动视角 | 锁定鼠标后移动鼠标 |
| 缩放镜头 | 鼠标滚轮 |
| 与附近建筑交互 | F |
| 打开个人管理窗口 | Tab |
| 返回、关闭窗口或打开暂停菜单 | Esc |
| 跳跃 | 空格 |
| 保存 | HUD 或系统菜单 |

普通业务窗口打开时人物操作锁定，但模拟继续；暂停菜单会停止模拟。部分业务需要到对应建筑现场办理。

## 当前限制

- 以桌面浏览器为主要目标，尚未完整适配移动端。
- 不包含战斗、车辆、多人联机或云存档。
- 房地产首版支持住宅和储备土地交易、居民月度购房及 AI 土地报价；暂不包含出租、按揭和私人地产开发。
- 企业产品的售价目前不影响销量，相关经济数值仍需后续平衡。
- 游戏 GDP 是内部发展指标，并非现实国民经济核算。
- 3D 地图和可见建筑不代表逐人、逐户模拟全市居民。
- 构建与局部验证通过不等于全部游戏体验已验证，仍需持续游玩反馈。
