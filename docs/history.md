# 项目简要历史记录

本文件汇总此前的阶段报告；当前行为、职责和约束以 `architecture.md`、`contracts.md` 和代码为准，决策依据见 `decisions.md`。历史报告和截图也可在 Git 提交 `cd76526` 中查看，例如 `git show cd76526:docs/furniture-editor-delivery.md`；历史验证不代表当前版本已经通过同样的验证。

- **经济与城市基础**：先后加入企业、资本、人口、政治、房地产、住房、生存、背包和商店等系统，形成应用层统一时间推进与财务边界；存档迁移和当前口径以现行契约为准。
- **建筑与环境**：模块化建筑接入正式地图，建筑规划尺寸和声明包络作为权威；实现游戏时间驱动的昼夜、天气与统一阴影。建筑视觉失败时保留占位和碰撞降级。
- **界面与住宅**：整合 HUD、Tab、Esc 菜单和晴川住宅室内，保留手动暂停、菜单暂停、室内会话与读档边界。
- **城市街区**：加入由只读布局派生的装饰街区、街景和模板，不改变经济地图。历史记录中指出转角与屋顶构件可能穿插、树木形态及视觉避让待检查，旧截图未必对应最后代码；真机画面与性能未完成全面验收。
- **住宅家具编辑**：加入家具布局、移动、旋转、收纳与摆放，存档升至 v20。历史交付指出部分挂件、台灯可悬空，部分地面装饰不阻挡人物；完整行为以现行家具契约为准。

更早的尺度测量和房地产参数设计仍分别见 `scene-scale.md` 和 `real-estate-design.md`；它们被当前代码或资源说明引用。当前 Rapier 与跳跃工作见 `player-jump-plan.md` 和 `rapier-physics-gptwork-task.md`。
