# 界面设计规范与功能入口映射（v0.3.4 · UI 重设计）

本轮只改表现层与入口组织：不新增玩法、不改存档格式、不改任何资金/权限/时间口径。
实现集中在 `src/ui/`，数据仍只来自 `app` 层的只读视图，写操作仍只经 `app` 层命令。

## 1. 视觉方向

- 主题：现代、清爽、亲和的城市生活与经营界面；城市画面始终是背景，管理界面是一层
  「浮在城市场景上的纸」。
- 管理窗口默认不铺满屏幕（`min(1240px, 100vw - 72px)` × `min(820px, 100vh - 88px)`），
  可拖动、可放大/恢复；透明与模糊只用于 HUD 边缘与浮层，管理窗口本体不透明，
  优先保证中文与数字的可读性。
- 股票绘图区是唯一允许的深色区域（深石墨蓝），与整体浅色形成「数据仪表」对比。

（窗口开关 140–180ms，悬停 90–120ms），并遵守 `prefers-reduced-motion`。

### 排版与尺度

- 字体：系统中文栈（Segoe UI → PingFang SC → Microsoft YaHei → Noto Sans SC 若已安装 →
  system-ui），不引入 Web 字体，取舍说明见 `public/assets/SOURCES.md`。
- 尺寸阶梯：12 / 12.5 / 13 / 14 / 16 / 18 / 20 / 27px；数字统一 `tabular-nums`。
- 间距：4 / 6 / 8 / 10 / 12 / 14 / 18 / 22px；圆角：18 / 12 / 8px；
  阴影只分「窗口」「卡片」「HUD」三档。
- 不使用全大写小标签做装饰标题，不用字形做装饰；信息层级只靠字号、字重与留白。

## 2. 窗口与 HUD

- 一个统一窗口 `src/ui/game-window.ts`（`.gw`）：标题栏可拖动、双击标题栏或右上角按钮
  放大/恢复，关闭按钮在右上角；拖动与缩放后整窗被夹在可视区域内，窗口尺寸变化时重新约束，
  标题栏与关闭按钮始终可点。
- 一次只打开一个主窗口；切换分类不重建容器。股票详情是辅助浮窗
  （`stock-window-manager.ts`），复用原有拖动/置顶/夹紧逻辑，**最多同时两个**，超出时关掉最早打开的。
- 窗口外层用 `gw-scrim` 遮罩承接点击关闭，点击窗口内部不会穿透到世界操作。
- 打开普通业务窗口时模拟继续；只有「系统菜单」入口保持原有暂停行为（Esc 打开即暂停）。
- Esc 顺序不变：先关最上层股票浮窗 → 再关整个窗口。
- HUD 只保留四块：左上时间与移动模式、右上资金、右上下方生存状态、底部交互提示与速度控制；
  面板打开时资金卡与交互提示隐藏、时间与速度控制锁定，规则与之前相同。

## 4. 图表规范

### 人口 / 产业环形图（`population-pie.ts`，原生 SVG）

- 扇区按真实比例绘制，颜色取自 8 色协调色板（蓝绿为主，暖色与紫灰为辅），
  图例同时给出分类名、人数与占比，信息不只靠颜色。
- 悬停或键盘聚焦：扇区沿中线外移 3.2px 并提亮（CSS transform，不参与布局，
  不改统计值、不撑大容器），中心摘要切换为该分类（名称 + 人数 + 占比），
  图例对应行同步高亮；点击图例一样会高亮扇区。
- 提示框显示分类名、人数与占比，位置跟随指针并按容器边界夹紧，不会超出窗口。
- 小比例扇区另有一条 26px 宽的透明命中环，0.3% 的扇区也能稳定悬停；扇区与图例都可 Tab 聚焦。
- 数据刷新时形状不变就只改弧长与文字，保留当前悬停对象与提示，不重播入场动画；
  页面重绘时 `data-preserve` 会把整块 SVG 搬到新位置，悬停不中断。
- 支持零数据（只有底环与 0 值图例）、单一分类（整环 + 总数）、小比例分类。
- 分类过多时不在环形图里强塞标签：政治人口 12 群体使用表格 + 边际明细，
  人口只用三层环形图。
- `prefers-reduced-motion` 下所有过渡降到 0.001ms。

### K 线（`stock-chart.ts`）

- 绘图区深石墨蓝，网格与坐标轴轻淡；右侧价格轴（含最新价标签）、底部时间轴按宽度取 2–3 个刻度。
- 蜡烛与影线同色，涨红跌绿（与全局一致）；未收盘的那根半透明；最新价用虚线标出。
- 悬停十字线联动时间轴标签、价格轴标签、图例中的开高低收与较前收涨跌；
  提示框跟随指针并夹在绘图区内。
- 默认窗口随历史增长自动展开（上限 90 根）：刚开局只有一根蜡烛时不会把窗口锁死在 1 根；
  用户滚轮缩放后固定为手动窗口，之后新数据不再改动它，只有「返回最新」才回到默认并重新跟随。
- 滚轮以光标位置为中心缩放（12 根至全量），按住拖动平移；「返回最新」恢复默认窗口并跟随最新一根。
- 画布按设备像素比重绘（上限 2.5），`ResizeObserver` 跟随窗口尺寸变化。
- 历史不足两根蜡烛时显示「正在积累行情」空状态；已终止证券显示「该证券已终止，不再生成行情」。
  界面不显示成交量、技术指标或不存在的历史字段。

## 5. 架构边界（本轮遵守情况）

- `src/ui/` 只读 `app` 层视图、只经 `PanelHandlers` 提交命令；没有新增对 `features` 实现的依赖。
- 窗口位置、放大状态、分类选择、子页、交易输入草稿、赞助草稿、图表缩放平移全部只在内存；
  新游戏/读档由 `resetPersonalSession` / `resetGovernmentSession` / `resetShopSession` 清理。
- 不新增依赖：无图表库、无图标包运行时、无状态管理库；`package.json` 未改动。
- 高频刷新沿用原策略并加强：输入或按住鼠标时只更新 `data-live` 数值节点；
  结构重绘时保留滚动位置、输入值与带状态的图形节点。
